## 🧩 About

**The Cycle Frontier Loot** is a comprehensive overlay for The Cycle Frontier featuring loot radar, item ESP, container ESP, loot filter, distance indicators, and customizable loot lists for Windows PC.

Based on popular mods like **OpenHack**, **Eclipse Menu**, and **QOLMod**.

---

## ✨ Features

### 🎒 Loot Radar
- Loot Radar — display nearby loot, containers, and resources
- Item ESP — highlight valuable items through walls
- Container ESP — show crates, safes, and hidden stashes
- Distance Indicators — see how far each loot is
- Loot Filter — choose which items to highlight

### 🎨 Overlay & UI
- Overlay Menu — toggle features with a hotkey
- Customizable Colors — set colors for each loot type
- Minimal Performance Impact — optimized for low-end PCs
- Stream-Proof Mode — hide overlay from screen capture

### ⚙️ Utilities
- Auto-Mark Loot — mark items on map for team
- Loot Log — record found items per raid
- Config Profiles — save and load settings
- Hotkey Manager — rebind all controls
